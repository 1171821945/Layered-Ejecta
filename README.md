Code:  EMHSEU UNET model and related ablation and comparative experiment related codes.  This code is based on the Python programming language and the PyTorch framework. Running train.py will create the specified model and start the training process. After each training epoch, the model's performance on the validation set will be evaluated, and the model with the best performance across various evaluation metrics will be automatically saved. Running acc_and_pre.py allows you to test and evaluate the trained model on the test dataset. The model creation is handled by the create() function in the create_model module. By specifying different model names (refer to the content of the create_model.py file), you can create different models.

LE_data_with_par.xlsx: Supplementary parameter information of layered ejecta crater. The five columns from left to right in the table represent the latitude, longitude, radius, EM, and Lobateness of the impact crater.
